- [ ] **A4 — §P1.6 Supernode pin-set cron** *(off PC2-node code, ops on supernode)*

- [ ] **A5 — §P0 Telemetry pipe — `POST /api/telemetry/onramp`**

  - SQLite table: `telemetry_onramp(event TEXT, ts INTEGER, install_id TEXT)`
  - Events: `install_started → wallet_ready → first_capsule_open → first_payment`
  - Single CSV/JSON dashboard rendered on a supernode at `dash.ela.city/onramp` (~100 LOC static HTML)
  - DoD: 4 events writable via owner-mode `POST`; aggregated counts readable via public `GET /api/telemetry/onramp/summary`; dashboard renders 4 cards
