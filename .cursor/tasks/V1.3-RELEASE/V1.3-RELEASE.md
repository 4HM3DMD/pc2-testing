# Task: v1.3 Release — Chipotle Production + V3 Contracts + PDR Phase B

**Task ID**: V1.3-RELEASE
**Created**: 2026-03-25
**Status**: Blocked
**Priority**: High

## Description

Ship v1.3.0 with three workstreams: (1) Lit Chipotle production swap, (2) Elacity V3 smart contract migration, (3) PDR Phase B — SDK extraction and enterprise API. All three are implementation-ready but blocked on external dependencies.

## Background

- The `feature/lit-chipotle-migration` branch contains all v1.2/v1.3 work (AI agent system, skills, canvas, voice, multi-agent, licensing metadata, content intelligence, publish queue)
- Lit Chipotle is fully implemented and tested on the **dev** network (`api.dev.litprotocol.com`)
- V3 smart contracts are audited and ready to deploy by the Elacity contract team
- PDR Phase B (SDK, Enterprise API, MCP) is blocked until Chipotle + V3 are on production

## Acceptance Criteria

- All existing V2 assets remain accessible (backward compatible)
- New mints use V3 contracts + Chipotle production
- Content Indexer scans both V2 and V3 content simultaneously
- Auto-provisioning works for fresh PC2 nodes on production Chipotle
- SDK modules are importable and testable independently
- Enterprise REST API accepts API key auth and returns JSON responses

## Known Risks

1. Dev-encrypted assets will NOT decrypt on production Chipotle (different PKP) — expected for test assets only
2. Media pipeline (video/audio) untested on Chipotle — needs dedicated testing
3. Vendor bundle rebuilds required for Creator/Market apps after V3 address update
4. Lit production may have per-operation costs — need cost model from Lit team
5. Two AuthorityGateway addresses must be reconciled in V3
