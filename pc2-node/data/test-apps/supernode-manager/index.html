What is a Supernode?
A supernode is a PC2 node that runs the full network stack: WireGuard/AmneziaWG/VLESS tunnels, IPFS relay, Boson DHT, web gateway, and app registry. Supernodes help other nodes connect to the network and earn revenue from Access Token holders.

Requirements: Public IP, 4+ CPU cores, 8+ GB RAM, 50+ GB free disk, Linux x64.
