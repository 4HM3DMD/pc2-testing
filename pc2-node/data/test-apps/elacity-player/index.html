Encrypted playback unavailable in this context

This page needs the browser's Web Crypto API (window.crypto.subtle) to decrypt protected content. The browser is currently denying access because the page wasn't loaded over a secure context (HTTPS, or http://localhost on the same machine).

If you are accessing PC2 on the same machine

Open the player using http://localhost:4200 instead of an IP address.

If PC2 is running on a remote server / VPS

Browsers block Web Crypto on plain HTTP over a public IP. You'll need to put HTTPS in front of PC2. Three quick options:

  • Caddy — automatic Let's Encrypt certs in 4 lines of config.
  • Cloudflare Tunnel — no firewall changes, no certs to manage.
  • nginx + certbot — classic reverse-proxy + Let's Encrypt setup.

See the setup guide: HTTPS for self-hosted PC2.

Things that won't fix this

  • Switching browser (Chrome / Firefox / Brave / Safari all enforce the same rule).
  • Updating PC2 (the restriction is browser-side, not server-side).
  • Disabling browser extensions.
